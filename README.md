# Бот 4-дневного марафона · метод «ФИНИШ»

Telegram-бот, который ведёт человека по бесплатному марафону Павла Андреева:
кружки, отзывы, записи четырёх дней, опросники между днями и кнопки покупки
в конце. Сделан по ТЗ от 30.08.2026.

## Быстрый запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # заполнить токен и чаты
python -m bot.main
```

Без заполненного `.env` бот не стартует и скажет, чего не хватает — это
намеренно: бот без чата покупок потеряет первую же заявку.

## Что нужно от заказчика для запуска

| Что | Зачем |
|-----|-------|
| `BOT_TOKEN` | токен от [@BotFather](https://t.me/BotFather) |
| `PURCHASE_CHAT_ID` | группа, куда падают заявки на покупку |
| `SUPPORT_CHAT_ID` | группа службы заботы |
| `ADMIN_IDS` | кто может грузить записи дней |
| Записи 4 дней | видео марафона (лежат у Алексея в Zoom) |

Чтобы узнать ID группы: создайте её, добавьте бота администратором, напишите
туда любое сообщение и перешлите его боту [@getmyid_bot](https://t.me/getmyid_bot).
ID группы отрицательный, вида `-1001234567890`.

## Куда заливать записи дней

Это вопрос из ТЗ, вот ответ. **Проще и надёжнее всего — в сам бот.**

Отправьте боту видео дня с подписью `day1` (или `day2`, `day3`, `day4`).
Бот запомнит его и дальше будет рассылать людям мгновенно.

Почему так:

- **Нет ограничения по размеру.** Бот не перезаливает файл, а отправляет
  ссылку на уже лежащий в Telegram — размер значения не имеет.
- **Человек не уходит из Telegram.** Не нужен ни YouTube, ни браузер;
  досмотры выше, ссылку не перешлёшь постороннему одним нажатием.
- **Ничего не платим** за хранение и трафик.

Загрузить видео в Telegram может любой аккаунт: до 2 ГБ, с Premium до 4 ГБ.
Если день длиннее — режем на части и грузим `day1` частями по очереди.

**YouTube «по ссылке» брать не советую:** в России он ощутимо замедлен, а
аудитория марафона в основном российская — часть людей просто не досмотрит.
Если всё же нужен внешний сервис (например, ради статистики досмотров) —
подойдёт Kinescope или VK Видео, бот умеет отправлять и ссылку:

```
day1 https://kinescope.io/xxxxx
```

## Записи уже лежат на сайте

Пока записи не залиты в бот с аккаунта, они отдаются страницами сайта
энергетического спортзала — файлы на том же VPS, ключ доступа в
`/etc/gym.env` (`MARATHON_KEY`), без него страница отдаёт 404:

```
day1 https://energy-sport-gum.ru/marathon/1?k=<ключ>
day2 https://energy-sport-gum.ru/marathon/2?k=<ключ>
day3 https://energy-sport-gum.ru/marathon/3?k=<ключ>
day4 https://energy-sport-gum.ru/marathon/4?k=<ключ>
```

Четыре сообщения боту — и дни уходят людям ссылкой. Когда записи зальют
в телеграм (видео с подписью `day1`), бот переключится на них сам: видео
в базе имеет приоритет над ссылкой.

## Как устроена воронка

| Шаг | Когда | Что уходит |
|-----|-------|------------|
| /start | сразу | приветствие + кнопка «Запустить» + кнопка службы заботы |
| Запуск | сразу | приветственный кружок Павла (две части) |
| Отзывы | +60 сек | 8 отзывов, по одному каждые 2 секунды |
| **День 1** | сразу за отзывами | запись + текст про ПРЕДНАЗНАЧЕНИЕ |
| Опросник 1 | +150 минут | кружок «посмотрел первый день?» + Да/Нет |
| **День 2** | +5 сек после кружка ветки | запись + текст про ОТНОШЕНИЯ |
| Опросник 2 | +120 минут | кружок «посмотрел второй день?» + Да/Нет |
| **День 3** | +30 сек после кружка ветки | запись + текст про ЗДОРОВЬЕ |
| Опросник 3 | +120 минут | кружок + Да/Нет |
| **День 4** | +3 сек после кружка ветки | запись + текст про ФИНАНСЫ |
| Продажа | +60 минут | кружок, через 2 сек кнопки покупки, следом кружок про заботу |

Весь путь — 7 часов 30 минут. Человек, начавший в 10 утра, доходит до кнопок
покупки к вечеру того же дня, и ни один шаг не приходится на ночь.

Ответы «Да» и «Нет» ведут к одному и тому же дню, но с разными кружками —
как в ТЗ. **Если человек не ответил вовсе**, через 12 часов бот сам ведёт его
по ветке «Нет» (она мягкая: «понимаю, бывают дела»). Иначе воронка встала бы
навсегда — следующий день привязан к ответу. Отключается `POLL_FALLBACK_HOURS=0`.

## Команды администратора

| Команда | Что делает |
|---------|------------|
| `/status` | что загружено, чего не хватает, сколько людей и заявок |
| `/test` | прогнать всю воронку на себе за ~10 минут (паузы сжаты в 60 раз) |
| `/live` | вернуть себе боевые сроки и очистить свою очередь |
| `/help` | памятка по загрузке материалов |

Загрузка материалов — просто отправить боту:

- видео с подписью `day1`…`day4` — запись дня;
- текст `day1 https://…` — ссылка вместо видео;
- фото с подписью `review1`…`review8` — отзыв картинкой вместо текста.

## Служба заботы

Кнопка есть с первого экрана и не исчезает. Всё, что человек пишет боту,
падает в чат заботы; менеджер отвечает **реплаем** на это сообщение, и ответ
возвращается человеку в бот. Переписка целиком остаётся в одном чате и видна
команде — в личку менеджера ничего не уходит.

## Кружки

Собраны из присланных `.MOV` скриптом:

```bash
python tools/circles.py
```

Что делает скрипт: разворачивает 4K-вертикаль с айфона, вырезает квадрат так,
чтобы лицо село в центр круга (кружок круглый — углы зритель не видит), жмёт
в 512×512 и режет по длине. Кроп и границы правятся в `tools/circles.json`,
код трогать не нужно.

## Разбор присланной пачки

```bash
python tools/inbox.py "C:/Users/Sharp/Downloads"
```

Заказчик шлёт кружки пачками, и имена при пересылке съезжают: один и тот же
файл приходил и как `IMG_0696`, и как `IMG_06936`, а под именем `IMG_0702` во
второй раз приехало содержимое `IMG_0701`. Скрипт сверяет содержимое по
отпечатку, а не по имени, и говорит: что новое, что уже есть под каким именем,
чего в пачке нет. Можно передать и конкретные файлы вместо папки.

## Заставка перед записью дня

```bash
python tools/intro.py
```

Берёт присланный заказчиком постер марафона (`media/intro/poster.mp4`),
вырезает из него горизонтальную полосу с заголовком и подписью Павла,
кладёт поверх номер и название дня в цвете его сферы — и приклеивает в
начало записи. Запись при этом не перекодируется: заставка собирается
ровно под её параметры, а склейка переписывает только контейнер, поэтому
двухчасовой день обрабатывается за минуту.

Заставка становится и обложкой в Telegram — превью берётся с первых кадров.

## Расшифровка кружков

```bash
python tools/transcribe.py
```

Расшифровывает присланные `.MOV` (faster-whisper, локально) и раскладывает
по ролям в воронке — какой файл где играет и что в нём говорится. Результат
в [РАСШИФРОВКА.md](РАСШИФРОВКА.md), там же разобраны расхождения между
подписями в переписке и содержимым видео. Повторный запуск берёт готовое из
`tools/_transcripts.json` и заново не считает.

## Деплой на Railway

Репозиторий: https://github.com/kbeautyg/botmarafon

1. New Project → Deploy from GitHub repo → `kbeautyg/botmarafon`.
2. **Подключить диск**: Settings → Volumes → Add volume, точка монтирования
   `/data`. Без него база живёт до первого перезапуска, а вместе с ней —
   очередь отложенных шагов и запомненные записи дней. Бот сам увидит `/data`
   и положит базу туда. Если диска нет, бот скажет об этом админам при старте
   и в `/status` («База не на диске»).
   Записи дней и отзывы-картинки бот дублирует в закреплённое сообщение у
   каждого админа (`#хранилище`) и после переезда контейнера возвращает сам —
   закреп не откреплять. Очередь шагов так не спасти, диск всё равно нужен.
   Ещё одна страховка — переменные `DAY1`…`DAY4` (file_id видео или ссылка):
   их бот берёт, когда в базе пусто. file_id бот показывает в ответе на
   загрузку записи, пока база не на диске.
3. Переменные (Variables):

```
BOT_TOKEN=<токен от @BotFather>
CARE_CONTACT=Metod_Finish_Official
PURCHASE_CHAT_ID=<чат заявок>
ADMIN_IDS=<id админов через запятую>
POLL_FALLBACK_HOURS=12
```

`SUPPORT_CHAT_ID` — только если заведут группу поддержки; кнопка заботы
работает и без неё, она ведёт прямо в аккаунт из `CARE_CONTACT`.

Дальше деплой идёт сам на каждый push в `main`.

**Важно:** телеграм отдаёт обновления одному слушателю. Пока бот работает
на Railway, локальный запуск надо погасить, иначе они будут перебивать друг
друга и часть сообщений людям не дойдёт.
